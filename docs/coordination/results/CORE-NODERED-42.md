Optional package: integrations/node-red. No runtime dependencies, no Node-RED server installed or started. Install this local package into an existing Node-RED user directory with `npm install F:/Modlists/AutoWizard101/integrations/node-red`, then restart that Node-RED instance. This is an optional developer integration, not yet a bundled app feature. No production dependency added to Maelstrom.

The maelstrom-local node calls the existing current-user Windows named pipe directly using the same root hash and length-prefixed JSON protocol. Set Data folder to the active owner's exact absolute data root. Start the existing Maelstrom deck owner separately. Topics catalog/capabilities/state/snapshot/preview/validate-routine are read-only; editing/execution commands require Allow actions plus a GUID-N request ID. Connect/observe/raw input/shell are deliberately not exposed. Explicit start/step still pass through the existing scheduler and admission guards. No action retries are automatic.

Send topic subscribe to sample published game facts (snapshot) or deck state (state); unsubscribe stops. Latest-state messages include subscription session UUID, monotonic sequence, snapshot/change/heartbeat/unavailable and sampledUtc. At most 1 Hz per subscription, no overlapping polls, no queued backlog, 8-second call timeout and 256-KiB frame limit. Disconnect invalidates the previous snapshot; reconnect emits a complete snapshot. Source observed timestamps/freshness/unknown fields remain untouched. Sample time must not be treated as observation time. This is bounded pull-based subscription, not lossless push events: intermediate transitions can be missed. Closing/redeploying aborts pending requests. A cancelled action is unconfirmed, not automatically cancelled gameplay; use owner stop separately and inspect state.
